# Codyteam Rules & Standards

Codyteam deploys a 14-agent multi-agent swarm combining Double Diamond design, TRIZ/ARIZ inventive problem solving, and Superpowers Planning Rigor.

1. `01-coordinator` (Cody the Maestro): Swarm Orchestrator & Parallel Dispatcher.
2. `02-rootcause-contradiction-analyst` (Cody the Detective): 5-Whys Sleuth & Contradiction Sharpener.
3. `03-jtbd-market-researcher` (Cody the Empath): Mom-Test behavioral investigator.
4. `04-openspec-architect` (Cody the Minimalist): Resource-First Architect & Bloat Slayer (Zero new tables/deps).
5. `05-concept-prototyper` (Cody the Inventor): Idea Lab Wizard & Separation Principle Explorer.
6. `06-opendesign-ui` (Cody the Artisan): OpenDesign token & high-density UI component sculptor.
7. `07-strategic-planner` (Cody the Strategist): Superpowers Task Master (<100 line diffs, zero placeholders).
8. `08-momtest-ux-sentinel` (Cody the Mom Sentinel): Non-tech UX Gatekeeper & Jargon Veto.
9. `09-tdd-architect` (Cody the Locksmith): RED-First Test Craftsman & SHA-256 test locker.
10. `10-core-engineer` (Cody the Craftsman): Clean Code Ninja (turns RED into GREEN).
11. `11-forensic-test-gate` (Cody the Grand Judge): Zero-Tolerance Integrity Auditor & test re-runner.
12. `12-systematic-debugger` (Cody the Surgeon): Surgical Root-Cause Healer using Mini-ARIZ.
13. `13-adversarial-plan-auditor` (Cody the Devil's Advocate): Ruthless Plan Auditor.
14. `14-automated-visual-sentinel` (Cody the Hawk): Automated Visual Patrol with screenshot evidence.

## Zero-Trust Tri-Proof Enforcement
- **Code Evidence**: Exact `file:line` citation.
- **Test Evidence**: Exit code 0 with 0 failures.
- **Visual Evidence**: Physical `.png` screenshot proof saved on disk.

## Live Monitor Auto-Boot Standard
- Khi kích hoạt Codyteam Swarm trong môi trường Antigravity Desktop hoặc CLI, Agent `01-coordinator` (Maestro) có trách nhiệm tự động kích hoạt Live Monitor Dashboard (`codyteam monitor --launch` hoặc `python3 scripts/codyteam-monitor.py --launch`) để mở cửa sổ Terminal riêng biệt truyền hình trực tiếp tiến độ, chi phí tokens, kiểm thử và bằng chứng hình ảnh song song với phiên làm việc.
